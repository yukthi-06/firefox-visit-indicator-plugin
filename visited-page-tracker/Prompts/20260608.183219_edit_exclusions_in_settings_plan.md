# Support Editing Excluded Sites/Patterns in Settings

We want to allow users to edit existing exclusion patterns directly within the options page table. This allows them to easily add/remove wildcards (`*`) or modify exact match URLs to regexes without having to delete and re-create them.

## Proposed Changes

### [options/options.ts](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-plugin-visit-indicator-xpi_GITHUB/visited-page-tracker/options/options.ts)
- Update `renderExcludedSites()` to support inline editing of rows.
- We will track the index of the row currently being edited (e.g., `let editingIndex: number | null = null;`).
- When a row is in edit mode:
  - The text cell changes to an `<input type="text">` containing the pattern.
  - The "Edit" and "Remove" buttons in the actions column are replaced with "Save" and "Cancel" buttons.
  - Clicking "Save" validates the updated pattern (ensures it is not empty, does not create duplicates besides itself, compiles if RegExp) and updates the settings list.
  - Clicking "Cancel" reverts `editingIndex = null` and re-renders the list.

### [options/options.css](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-plugin-visit-indicator-xpi_GITHUB/visited-page-tracker/options/options.css)
- Add styling for the inline edit inputs in the table cells to ensure they fit properly and look premium (aligned, rounded corners, focus styles matching the rest of the application).
- Add styling for action buttons: "Edit", "Save", "Cancel" to look consistent and clean.

## Verification Plan

### Automated Tests
- Run build to make sure TypeScript compiles successfully.

### Manual Verification
- Open the settings page.
- Add an exclusion like `https://example.com/foo`.
- Click the "Edit" button on the newly added row.
- Verify the row converts to an input field and displays "Save" and "Cancel" buttons.
- Change the value to `https://example.com/*` and click "Save".
- Verify the list updates and saves successfully.
- Click "Edit" again, change the text, and click "Cancel" to verify changes are reverted.
