# Walkthrough: Support Exact Match, Wildcards, and Regex in Site Exclusions

We have updated the exclusion logic of Visited Page Tracker to support exact match by default, wildcard match with `*`, and regex pattern matching.

## Changes Made

### 1. Matching Logic
- Added `isUrlExcluded(url, excludedList)` helper function in [urlUtils.ts](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-plugin-visit-indicator-xpi_GITHUB/visited-page-tracker/shared/urlUtils.ts) which handles:
  - Exact match of the full URL or domain name.
  - Wildcard match using `*`.
  - RegExp matching if the pattern is wrapped in slashes (e.g. `/^https:\/\/.../i`).

### 2. Service Worker & Content Script
- Updated [background.ts](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-plugin-visit-indicator-xpi_GITHUB/visited-page-tracker/background/background.ts) and [content.ts](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-plugin-visit-indicator-xpi_GITHUB/visited-page-tracker/content/content.ts) to utilize `isUrlExcluded` instead of simple hostname checks.
- Updated `EXCLUDE_SITE` message handler to save exact URLs when requested.

### 3. Page Banner
- Updated the "Exclude from tracking" button in [banner.ts](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-plugin-visit-indicator-xpi_GITHUB/visited-page-tracker/content/banner.ts) to exclude the **exact page URL** by default instead of the entire domain, and renamed button/labels to "Exclude this page from tracking" to clarify the behavior.
