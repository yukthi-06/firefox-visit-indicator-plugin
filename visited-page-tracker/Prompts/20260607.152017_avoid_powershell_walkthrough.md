# Walkthrough: Avoid PowerShell in NPM commands

## Changes Made

### visited-page-tracker

#### [MODIFY] [package.json](file:///x:/Projects_X/0_Active/A_XPI_Firefox_Plugin/firefox-visit-indicator-plugin-xpi_GITHUB/visited-page-tracker/package.json)
- Replaced the PowerShell command in the `"package"` script with a Node.js-based cross-platform inline script.

Before:
```json
"package": "npm run build && npx web-ext build --source-dir=dist --artifacts-dir=artifacts --overwrite-dest && powershell -NoProfile -Command \"Get-ChildItem artifacts\\*.zip | ForEach-Object { Rename-Item $_ ($_.FullName -replace '\\.zip$','.xpi') }; Write-Host 'XPI ready in artifacts\\'\"",
```

After:
```json
"package": "npm run build && npx web-ext build --source-dir=dist --artifacts-dir=artifacts --overwrite-dest && node -e \"const fs = require('fs'); const path = require('path'); const dir = 'artifacts'; fs.readdirSync(dir).forEach(file => { if (file.endsWith('.zip')) { fs.renameSync(path.join(dir, file), path.join(dir, file.replace(/\\.zip$/, '.xpi'))); } }); console.log('XPI ready in artifacts/');\"",
```

## Verification

Due to sandbox directory write access constraints, the package script execution was not verified locally by the AI agent. However, the Node.js implementation relies on native `fs` functions which are standard and cross-platform (working on Windows, macOS, and Linux).
