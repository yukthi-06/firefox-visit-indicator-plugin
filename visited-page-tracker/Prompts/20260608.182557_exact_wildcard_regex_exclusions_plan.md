# Support Exact Match, Wildcards, and Regex in Site Exclusions

We want to enhance the exclusion logic of Visited Page Tracker to:
1. Make exact URL (or domain) matching the default behavior.
2. Support wildcard matching via `*`.
3. Support regular expression matching via `/pattern/flags` syntax.
4. Update the settings page to describe these options and handle less restrictive validation.
