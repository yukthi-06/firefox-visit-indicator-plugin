# Exclude Sites from Tracking Plan

Add a feature to exclude specific hostnames/sites from tracking. The user will be able to exclude the current site directly from the notification banner ("Exclude this site from tracking"), and view/edit/remove these exclusions from a new "Excluded Sites" section in the options/settings page.

## User Review Required

> [!NOTE]
> - "Exclude this site" will extract the hostname (e.g., `github.com` or `www.google.com`) of the current tab and exclude it.
> - Excluded sites will not show the banner, won't show the highlight, and won't have new visits recorded.
> - The list of excluded sites will be persisted in the user settings synced via storage.

2. Click the new "Exclude this site from tracking" button.
   - Verify banner and overlay disappear instantly.
3. Refresh the page or visit other pages on the same site.
   - Verify that no banner/overlay appears, and visit count is NOT incremented.
4. Open Options Page.
   - Verify that the domain appears in the "Excluded Sites" list.
   - Test adding a new site (e.g., `example.org`) from the Options Page.
   - Test removing a site from the Options Page.
   - Verify that after removal, visiting the site resumes tracking.
