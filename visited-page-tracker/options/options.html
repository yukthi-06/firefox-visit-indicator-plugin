🎨 Display Settings

Display a notification banner at the top of previously visited pages showing when you last visited and how many times.

💾 Storage Backend

Browser Storage (recommended): Uses Firefox's built-in storage. No setup required.
Native File Storage: Writes to a JSON file on your disk. Requires installing the native host application. See the README for setup instructions.

⚠️
Native Host Required
Native file storage requires the VPT host application to be installed. If it's not installed, the extension will automatically fall back to browser storage. View installation instructions

🚫 Excluded Pages / Patterns

Specify pages or pattern matchers that should be excluded from tracking. The banner and highlight will never be shown on matching URLs:
  • Exact match (default): e.g. https://example.com/docs (excludes only that URL) or example.com (excludes the home page or matching hostname exactly).
  • Wildcards: Use * to match anything, e.g. *.wikipedia.org/* (excludes any wiki page).
  • Regex patterns: Wrap in slashes, e.g. /^https:\/\/github\.com\/.*$/i.

ℹ️ About

Visited Page Tracker maintains a private, local history of pages you visit — completely independent of Firefox's built-in history.

All data is stored entirely on your device. No data is ever transmitted externally. No analytics. No telemetry.
