Build a production-quality Firefox WebExtension called "Visited Page Tracker" with the following requirements.

# Goal

The extension should maintain a local history datastore independent of Firefox's built-in history.

Whenever a user visits a page:

1. Record the URL and current timestamp in a persistent file-based datastore if possible.
2. On subsequent visits to the same URL:

   * Display a prominent banner at the top of the page saying:

     "You last visited this page on <timestamp>"

   * Change the page background color slightly so the user immediately recognizes it as a previously visited page.

The extension should work automatically on all normal web pages.

# Technical Requirements

## Browser

Target Firefox using the latest WebExtensions Manifest V3 APIs.

## Storage

Preferred:

* File-based datastore.

However, Firefox WebExtensions do not normally allow arbitrary filesystem writes.

Therefore implement:

Option A (default):

* Use browser.storage.local as the persistence layer.

Option B (advanced mode):

* Create a Native Messaging Host that writes records to a JSON file on disk.
* Keep the code structured so the storage layer can be swapped between:

  * browser.storage.local
  * native messaging file storage

Use an abstraction:

```typescript
interface VisitStore {
    getVisit(url: string): Promise<VisitRecord | null>;
    saveVisit(record: VisitRecord): Promise<void>;
}
```

## Data Model

```typescript
interface VisitRecord {
    url: string;
    firstVisited: number;
    lastVisited: number;
    visitCount: number;
}
```

Store timestamps as "yyyy-MM-dd.hhmmss".

## Visit Logic

When a page loads:

1. Normalize URL:

   * remove fragment/hash
   * preserve query string
   * preserve protocol
   * preserve path

Example:

[https://example.com/page?id=1#section](https://example.com/page?id=1#section)

becomes

[https://example.com/page?id=1](https://example.com/page?id=1)

2. Check datastore.

3. If URL exists:

   * Capture previous lastVisited timestamp.
   * Increment visitCount.
   * Update lastVisited to current time.
   * Display banner using previous timestamp.

4. If URL does not exist:

   * Create record:

     * firstVisited = now
     * lastVisited = now
     * visitCount = 1
