# User Prompt

Build a production-quality Firefox WebExtension called "Visited Page Tracker" with the following requirements.

## Goal
The extension should maintain a local history datastore independent of Firefox's built-in history. Whenever a user visits a page:
1. Record the URL and current timestamp in a persistent file-based datastore if possible.
2. On subsequent visits to the same URL, display a prominent banner and change the page background color.

## Key Design Decisions

1. **Storage Abstraction**: VisitStore interface allows swapping between localStore and nativeStore without touching content/background logic.
2. **Background Service Worker**: All storage ops happen in background to keep content scripts lean.
3. **SPA Detection**: Override history.pushState/replaceState + popstate listener in content script.
4. **Atomic Writes**: Native host uses write-to-temp-then-rename for data safety.
5. **Performance**: browser.storage.local uses direct key lookup (URL as key), O(1) access.
6. **Security**: No external network calls; content_security_policy set to block all external resources.

## Build Steps

1. `npm install` — install TypeScript, webpack, Jest, @types/firefox-webext-browser
2. `npm run build` — webpack bundles TS into dist/
3. Load dist/ folder in Firefox as temporary extension
