Then in Firefox: `about:debugging` → Load Temporary Add-on → select `dist/manifest.json`

## Key Design Decisions

1. **Storage abstraction**: `VisitStore` interface means one-line swap between backends
2. **Background-only storage**: Eliminates race conditions across multiple tabs
3. **SPA detection**: Patches `history.pushState/replaceState`; debounced 100ms
4. **In-flight deduplication**: Map of Promises prevents duplicate writes for same URL
5. **Atomic file writes**: temp-file-then-rename prevents JSON corruption
6. **CSS isolation**: `all: unset` + `!important` guards protect banner from host styles
7. **Auto-fallback**: NativeStore transparently falls back to LocalStore if host unavailable
